# Contexto del proyecto

**Despensa Nahuel** es una aplicación Windows offline-first para que Lili gestione una despensa desde la PC del negocio sin conocimientos técnicos ni contables. Debe ayudar a vender normalmente y saber qué comprar, cuánto se gana y dónde se va el dinero.

Stack: Tauri 2 + React + Vite + TypeScript + SQLite local. Módulos previstos: POS, productos, compras, stock, gastos, caja, resultados y reposición. Estado: núcleo operativo implementado para catálogo, inventario, compras/costos y ventas; gastos, caja, resultados y reposición siguen pendientes.
